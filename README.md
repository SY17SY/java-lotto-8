# 우아한테크코스 8기 프리코스 - 3주차: Lotto

## 기능 목록

- [ ] 입력 받은 구입 금액만큼의 로또를 생성한다.
- [ ] 입력 받은 숫자 6개와 보너스 숫자를, 생성한 로또와 비교한다.
- [ ] 결과와 수익률을 계산한다.

---

## 예외 목록 (IAE 발생)

### 구입 금액 입력값

- [ ] 숫자가 아닌 문자가 포함된 문자열을 입력 받을 때: "구입 금액의 형식이 올바르지 않습니다."
- [ ] 소수값을 입력 받을 때: "구입 금액의 형식이 올바르지 않습니다."
- [ ] int 범위를 넘는 값을 입력 받을 때: "구입 금액의 형식이 올바르지 않습니다."

### 구입 금액 비즈니스 검증

- [ ] 음수를 입력 받을 때: "구입 금액은 0보다 커야 합니다."
- [ ] 1,000원 단위가 아닌 값을 입력 받을 때: "구입 금액은 1,000원 단위이어야 합니다."

### 로또 번호 비즈니스 검증

- [ ] 숫자의 개수가 6개가 아닐 때: "로또 번호는 6개여야 합니다."
- [ ] 로또 번호 List 내에 중복되는 로또 번호가 존재할 때: "로또 번호는 서로 다른 수이어야 합니다."

### 당첨 번호 입력값

- [ ] 빈 문자열을 입력 받을 때: "당첨 번호를 작성해 주십시오."
- [ ] 구분자(,)가 없는 문자열을 입력 받을 때: "당첨 번호가 쉼표(,)로 구분되지 않았습니다."
- [ ] 구분된 문자열 중, 숫자가 아닌 문자가 포함될 때: "당첨 번호의 형식이 올바르지 않습니다."
- [ ] 구분된 문자열 중, 소수값이 포함될 때: "당첨 번호의 형식이 올바르지 않습니다."
- [ ] 구분된 문자열 중, int 범위를 넘는 값이 포함될 때: "당첨 번호의 형식이 올바르지 않습니다."

### 보너스 번호 입력값

- [ ] 빈 문자열을 입력 받을 때: "보너스 번호를 작성해 주십시오."
- [ ] 숫자가 아닌 문자가 포함된 문자열을 입력 받을 때: "보너스 번호의 형식이 올바르지 않습니다."
- [ ] 소수값이 포함될 때: "보너스 번호의 형식이 올바르지 않습니다."
- [ ] int 범위를 넘는 값이 포함될 때: "보너스 번호의 형식이 올바르지 않습니다."

### 당첨 번호, 보너스 번호 비즈니스 검증

- [ ] 1~45 범위를 이탈하는 숫자가 포함될 때: "당첨 번호 및 보너스 번호는 1부터 45 사이의 숫자여야 합니다."
- [ ] 당첨 번호의 경우, 숫자의 개수가 6개가 아닐 때: "쉼표(,)로 구분된 6개의 당첨 번호를 작성해 주십시오."
- [ ] 당첨 번호 List 내에 중복되는 당첨 번호가 존재할 때: "당첨 번호는 서로 다른 수이어야 합니다."
- [ ] 당첨 번호와 보너스 번호가 중복될 때: "당첨 번호와 보너스 번호는 서로 다른 수이어야 합니다."
